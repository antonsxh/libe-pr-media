# libe-pr-media

Screenshots and recordings for pull requests in [antonsxh/libe](https://github.com/antonsxh/libe).
They live here so that `libe` itself never carries PR-only images in its history.

- One folder per pull request: `<pr-number>/<name>.png` (or `.mp4`, `.webm`, …).
- Embed in the PR with `https://raw.githubusercontent.com/antonsxh/libe-pr-media/main/<pr-number>/<name>.png`.
- Never upload secrets: no tokens, pairing codes, setup secrets or private data in a screenshot.

Contributors can simply drag images into the PR description on GitHub instead; this repo is
for uploads from the command line (coding agents), since the GitHub API has no attachment upload.
